TakeUUp Portal - Project Status & QA Tester's Guide

Comprehensive Status Report, Module Dynamic States, and QA Test Scenarios

1. System Architecture Overview

The TakeUUp portal is built using a modern 3-Tier Clean Architecture stack:

  • Frontend: React.js, TypeScript, Tailwind CSS, Lucide icons, Vite bundling.
  • Backend: ASP.NET Core Web API (.NET 8/9), Entity Framework Core (EF Core) Object-Relational Mapper.
  • Database: SQL Server (Express/MSSQL) database engine.

2. Detailed Feature Catalog & Dynamic Status

Below is the detailed state of each module in the Student Portal, highlighting what is connected to the database and what remains static or mocked.

Authentication & Role Redirection

Fully Dynamic

Description: User registration, login verification using email/phone and OTP.

Implementation: Connected to `AuthController` and `OtpVerifications` table. Students are automatically redirected to /dashboard on success.

Target Goals & Subject Progress Tracker

Fully Dynamic

Description: Allows selecting multiple preparation goals, shows subjects in each goal, displays progress badges, and contains range sliders to adjust progress manually.

Implementation: Synchronized with the backend userProfiles table via UserProfileController using serialized JSON strings (TargetGoalsJson, UnlockedGoalsJson, GoalProgressJson). Actions are debounced by 1.5s.

Daily Routine Checklist

Fully Dynamic

Description: Students can list daily study tasks, mark tasks done, and track completion percentage.

Implementation: Renders dynamically and syncs checklist actions automatically to RoutineTasksJson in the SQL Server database.

Offered Courses & Category Exploration

Fully Dynamic

Description: Shows active courses, module completion checks, and category cards (HSC, Admission, BCS, Job Prep) with dynamic navigation.

Implementation: Course listings are dynamic. Added "Explore All Categories" section mapping to dynamic learning paths.

Quizzes & Mock Exams Workspace

Fully Dynamic

Description: Practice quizzes, chapter-wise MCQs, mock tests.

Implementation: Embedded inside the dashboard layout with dark theme. Fetches questions dynamically from QuizzesController and matches user category.

Friday Mega Quiz Arena

Fully Dynamic

Description: Weekly live mega quiz showdown held every Friday at 8 PM.

Implementation: Renders in-dashboard. Integrates with the backend leaderboard and registration endpoints.

Question Bank Archive & Horizontal Selector

Fully Dynamic

Description: Archive of previous years' exams and boards. Features a top horizontal scrolling tab bar in place of vertical sidebars.

Implementation: Parses database questions dynamically to map them to years and boards (e.g. 45th BCS, HSC 2023). Automatically pulls custom subjects from DB questions.

Find a Mentor

Fully Dynamic

Description: Mentor directory where students can search and filter mentors by subject and institution.

Implementation: Embedded inside the dashboard. Pulls data dynamically from `MentorsController` and database `Mentors` table.

Mobile Wallet Checkout Payment Gateway

Interactive Simulation

Description: Secure billing flow to unlock premium goal tracks.

Implementation: Simulated bKash, Nagad, and Rocket checkouts with wallet verification, OTP, and PIN confirmation. Updates database unlocked status on success.

Subject Action Hub (Preparation Room & Mock Tests)

Fully Dynamic

Description: Action selector popup when clicking on a subject progress card, displaying two options (Preparation Room and Mock Test Practice).

Implementation: Renders matching layout, color gradients, and icons from the reference screenshot. Routes internally to correct tabs.

Study Circles & Messaging (Groups)

Static Mock

Description: Collaboration workspace and group chat.

Implementation: Front-end renders a dummy UI. Messaging data is currently stored in local state and does not post to backend database.

4. Recommended Future Features

To make the portal even more competitive, we suggest adding the following features in subsequent updates:

1. AI Smart Study Companion (Chatbot)

An AI study tutor embedded on the sidebar that students can chat with to resolve doubts in specific subjects (e.g. solve a physics math or translate a sentence).

2. Student Gamification (Leaderboards & Streaks)

Display a global leaderboard on the dashboard overview showing students ranked by points. Add weekly challenges (e.g., "Solve 5 Math Quizzes") to earn reward badges.

3. Interactive Live Study Board

A digital whiteboard inside study circles where multiple students can draw, solve equations, and share notes in real-time using WebSockets.
